\section{Introduction}

Wind speed forecasting is valuable for grid operators managing Finland's growing
wind energy capacity. Wind energy consumption has been stably growing from year 2015
and in year 2024, the share of Finland energy consumption that war produced with wind
energy was 24\% \cite{StatisticsFinland2025}.

The Finnish Meteorological Institute (FMI) provide extensive data on their station
network publicly. They operate a dense network of stations across Finland and this
report test the hypothesis if creating a collaborative federated learning (FL)
network might help create better wind speed predictions compared to local models.

Using federated learning is relevant for these types of weather prediction problems
because raw station data might be commercially sensitive or subject to data-residency
constraints thus ruling out centralized training. Another reason to use federated
learning is if the data is sparse or the sensors are prone to making
mistakes, local models can borrow predictive power from neighboring stations to
improve their own predictions. \cite{McMahan2017}

The objective of this report is to create a federated model that predicts the next-hour
wind speed from the three previous hours. The report trains a local linear model
and then creates a FL graph that encodes which stations should influence each other
during training. The key design question in this report is wether the choice of the
graph topology (geographic vs. correlation-based) meaningfully affect the
forecasting accuracy.

The local model for each station is a simple linear regression:

$$
	\hat{y}^{(i)} = (\mathbf{w}^{(i)})^\top \mathbf{x}
$$

A bias column is appended to the weight matrix and the feature vector
is appended with $1$.

The loss function is mean squared error (MSE):

$$
	L_i(\mathbf{w}^{(i)}) = \frac{1}{|\mathcal{D}^{(i)}|} \sum_{(\mathbf{x}, y) \in \mathcal{D}^{(i)}} \left( (\mathbf{w}^{(i)})^\top \mathbf{x} - y \right)^2
$$

MSE is fairly standard in for linear regression models because it computes the
mean of the squared errors ot the predictions and true labels. Squaring the error
term penalizes larger errors.

This report compares two methods for graph constructions. The fist system is based
station geography. The fist graph construction method connects each station to its
$k = 5$ nearest neighbors. The distance between two stations is computed using
Haversine distance to take into account global curving.

Edges weights in the Geographic k-NN system are also based on the Haversine
distance

$$A_{ij} = \exp \left( \frac{-d_{ij}^2}{\sigma^2} \right) $$

where $\sigma$ is the median squared pairwise distance.

System 2 connects each station to its $k = 5$ most correlated neighbours. The
correlation is measured with Pearson correlation on 2024 wind speed series:

$$
	A_{ij} = \frac{\sum_{t=1}^{T} (y_t^{(i)} - \bar{y}^{(i)})(y_t^{(j)} - \bar{y}^{(j)})}{\sqrt{\sum_{t=1}^{T}(y_t^{(i)} - \bar{y}^{(i)})^2 \sum_{t=1}^{T}(y_t^{(j)} - \bar{y}^{(j)})^2}}.
$$

This graph construction method should in theory be able to capture meteorological
similarities beyond just geological proximity.

\section{Methodology}
\label{sec:meth}

Variation measure

\begin{itemize}
	\item The GTV penalty uses the squared $\ell2$ norm

	      $$
		      |\mathbf{w}^{(i)} - \mathbf{w}^{(j)}|^2
	      $$

	      to measure disagreement between neighboring stations' parameters
	\item Natural choice for linear models since parameters live in $\mathbb{R}^d$, convex, and differentiable. This makes the overall objective tractable. EXPLAIN THIS MORE OR FIND CITATION!!
\end{itemize}

GTVMin Objective

\begin{itemize}
	\item Write out the full problem:

	      $$
		      \min_{\mathbf{w}^{(1)},\dots,\mathbf{w}^{(n)}} \sum_{i=1}^{n} L_i(\mathbf{w}^{(i)}) + \alpha \sum_{{i,j} \in \mathcal{E}} A_{ij} |\mathbf{w}^{(i)} - \mathbf{w}^{(j)}|^2
	      $$

	\item Explain the parameters: $\alpha$ is the collaboration strength. If $\alpha = 0$ there is no penalty for differing models. If $\alpha = \infty$, all stations will share their model.
\end{itemize}

FL algorithm

\begin{itemize}
	\item GTVMin solved with synchronous federated gradient decent (FedGD)
	\item Derived from the fixed-point equation by iterating the block-wise minimization operator $\mathcal{F}^{(i)}$
	\item WRITE THIS SECTION OUT MORE IF YOU HAVE ROOM IN THE FIVE PAGE LIMIT!!
\end{itemize}

Update rule

\begin{itemize}
	\item Write the per-iteration update:

	      \begin{equation*}
		      \begin{split}
			      \mathbf{w}^{(i,t+1)} = \mathbf{w}^{(i,t)} - \eta \Bigl[ \nabla L_i(\mathbf{w}^{(i,t)}) \\
				      + 2\alpha \sum_{j \in \mathcal{N}(i)} A_{ij}\left(\mathbf{w}^{(i,t)} - \mathbf{w}^{(j,t)}\right) \Bigr]
		      \end{split}
	      \end{equation*}

	\item First term: gradient of local MSE. This pulls the model toward fitting the station's own data
	\item Second term: weighted disagreement with neighbors. This pulls the model toward agreement with similar stations
\end{itemize}

Message passing

\begin{itemize}
	\item Each iteration: node $i$ broadcasts $\mathbf{w}^{(i, t)}$ to all its neighbors and receives $\mathbf{w}^{(j, t)}$ from each neighbor $j \in \mathcal{N}(i)$
	\item All nodes update simultaneously using the same snapshot of weights (synchronous)
	\item Raw data $\mathcal{D}^{(i)}$ never leaves the node $i$. Only model parameters are communicated.
	\item Communication cost $2|\mathcal{E}|$ messages per station
\end{itemize}


\section{Numerical Experiments}
\label{sec:experiments}

Data source

\begin{itemize}
	\item FMI Open Data, hourly observations throughout 2024
	\item ~50 stations retained after applying the 80\% completeness filter
	\item Variables fetched: wind speed, temperature, relative humidity and atmospheric pressure
\end{itemize}

Train/val/test split

\begin{itemize}
	\item Chronological split. 70\% train, 15\% validation, 15\% test
	\item Temporal order must be preserved to avoid leakage (future data must never inform past predictions)
\end{itemize}

Hyperparameter selection

\begin{itemize}
	\item Regularization strength $\alpha$ selected via grid search over $[0.0, 0.01, 0.1, 0.5, 2.0, 5.0]$
	\item Each candidate $\alpha$ is evaluated by running FedGD for a fixed number of iterations and measuring mean validation MSE across all stations
	\item Best $\alpha$ is selected separately for each system
\end{itemize}
